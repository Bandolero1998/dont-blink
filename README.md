# DON'T BLINK

A tiny one-finger arcade game built as a mobile-friendly offline-capable web game.

## Play
Once GitHub Pages finishes deploying, open the Pages URL on your phone. In Safari, use **Share → Add to Home Screen** for an app-like full-screen shortcut.

## Controls
- Hold the screen to close the eye and pass through red laser gates.
- Release to open the eye and collect gold stars.
- A mistake ends the round. Your best score is stored locally on the device.

## Deploy
GitHub Actions deploys the repository root to GitHub Pages on every push to `main`.
